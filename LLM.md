# LLM.md : utilisation de l'IA dans le projet

## Modèle utilisé
- Claude (Anthropic), modèle Claude Sonnet 5.5, via l'application Claude (claude.ai)

## Documents de contexte fournis
- Notre code de l'atelier 5 (program.c)
- Des captures d'écran de notre éditeur et de notre terminal

## Prompts clés
1. « Propose nous différentes iddées pour que l'on puisse crée une regle du jeu »
   - Résultat : l'IA a crée les regles de la première version du jeu à deux joueurs et nous l'a expliquée.

## Rôle de l'IA
- L'IA a écrit la première version du code du jeu à deux joueurs, en partant de notre code de
  l'atelier 5, et nous a expliquée sur les lignes là ou nous bloquions.
- Nous : nous avons compilé et testé le jeu et joué plusieurs parties.
